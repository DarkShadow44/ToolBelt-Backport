# ToolBelt Backport

A belt to carry your tools in, for Minecraft 1.7.10. Backport of [gigaherz's Tool Belt](https://github.com/gigaherz/ToolBelt)
(based on the 1.12.x branch, plus the dyeable belt and config options from later versions).

- Craft a belt (string, leather, iron ingot), right-click it to put tools in.
- Wear it in the belt slot (`V`) or, with Baubles / Baubles Expanded installed, in a bauble belt slot.
- Hold `R` to pick a tool from the radial menu.
- Upgrade the belt in an anvil with a belt pouch, up to 9 slots.
- Dye it like leather armor.
